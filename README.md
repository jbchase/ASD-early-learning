# Genetic changes linked to two different syndromic forms of autism enhance reinforcement learning in adolescent male but not female mice
### Abstract: 
Autism Spectrum Disorder (ASD) is characterized by restricted and repetitive behaviors and social differences, both of which may manifest, in part, from underlying differences in corticostriatal circuits and reinforcement learning. Here, we investigated reinforcement learning in developing mice with mutations in either Tsc2 or Shank3, both high-confidence ASD risk genes associated with major syndromic forms of ASD. Using an odor-based two-alternative forced choice (2AFC) task, we tested early adolescent mice of both sexes and found male Tsc2 and Shank3B heterozygote (Het) mice showed enhanced learning performance compared to their wild type (WT) siblings. No gain of function was observed in females. Using a novel reinforcement learning (RL) based computational model to infer learning rate as well as policy-level task engagement and disengagement, we found that the gain of function in males was driven by an enhanced positive learning rate in both Tsc2 and Shank3B Het mice. The gain of function in Het males was absent when mice were trained with a probabilistic reward schedule. These findings in two ASD mouse models reveal a convergent learning phenotype that shows similar sensitivity to sex and environmental uncertainty. These data can inform our understanding of both strengths and challenges associated with autism, while providing further evidence that sex and experience of uncertainty modulate autism-related phenotypes.

## Repository layout
 
```
.
├── code/
│   ├── mat_to_csv/     MATLAB: parse raw behavior .mat logs into per-session behaviorDF.csv
│   ├── ITL/            Python: "inferred trials to learn" (ITL) analysis pipeline
│   ├── behavior/       MATLAB: reported behavior performance (3-hour block + quartile learning curves)
│   ├── exploratory_not_reported/ MATLAB: analyses run during revision but not in the manuscript
│   └── modeling/       MATLAB: reinforcement-learning modeling code and data (own README)
├── data/
│   ├── csvs/           behavior .csv per animal/session, in 6 group folders
│   └── metadata/       one row per session (age, date, genotype, sex, ...)
└── results/
    └── ITL/            ITL outputs, one folder per group
```

## Requirements
 
- **ITL pipeline (Python):** Python 3.9+ with `pandas`, `numpy`, and `matplotlib`, plus Jupyter to run the notebook. (No other third-party packages are required.)
- **Behavior pipeline (MATLAB):** MATLAB with the Statistics and Machine Learning Toolbox. The exploratory FDA test additionally uses the Curve Fitting Toolbox (see `exploratory_not_reported/`).
- **Modeling pipeline (MATLAB):** MATLAB R2022a with the Optimization, Global Optimization, Parallel Computing, and Statistics and Machine Learning Toolboxes. See `code/modeling/README.md`.

## Pipelines
 
### 1. Behavior preprocessing: raw `.mat` → `.csv`  (MATLAB, `code/behavior/` + `code/mat_to_csv/`)
 
- `code/behavior/master_ASD_RLWM_JC.m` builds a session index (`makeDataIndex_ASD.m`) and converts each raw `.mat` behavior log into a `behaviorDF.csv` via `extract_behavior_df` / `get_RLWM_EventTimes`(in `code/mat_to_csv/`). Set `root_dir` and `strainNum` at the top of the driver, and `code/mat_to_csv/`, `code/behavior/`, and its `plot/` and `lib/` subfolders to the MATLAB path.
The `behaviorDF.csv` files in `data/csvs/` were generated by these utilities.
 
### 2. ITL analysis  (Python, `code/ITL/`)
 
- Open `ITL_analysis.ipynb` and set the paths to the metadata, output folder, and behavior CSVs. Running it reproduces the per-group folders under `results/ITL/`. 
Helpers: `analysis.py`, `tail_analysis.py`,`trimming.py`.
 
### 3. Behavior performance: 3-hour block + quartile curves  (MATLAB, `code/behavior/`)
 
- `ASD_odor_summary.m` — 3-hour block performance in AB; writes the per-block/quartile performance CSVs.
- `ASD_learning_curve.m` — quartile learning curves in AB.
Summary values from both scripts were exported and the final figures and statistics (Mann–Whitney U, two-way repeated-measures ANOVA) were produced in GraphPad Prism — see Reproducibility notes.
 
### 4. Reinforcement-learning modeling  (MATLAB, `code/modeling/`)
 
Trial-by-trial Session-1 choice data are fit with a family of RL models (winning model: a hybrid that alternates between an engaged RL policy and a disengaged side-biased policy via an HMM). Full layout, cohort table, and usage are in `code/modeling/README.md`.

## Data
 
- `data/csvs/` — individual behavior `.csv` for each animal's session, separated into 6 folders by group
  (Tsc2 / Shank3B × sex × deterministic/probabilistic).
- `data/metadata/` — one row per session with age, date, genotype, sex, etc.
## Results
 
- `results/ITL/` — ITL outputs with one folder per group: trial-level summaries, cutoffs at the 93rd,
  95th, and 98th percentiles, and a shorter `.csv` with the 95th-percentile data used for the
  supplemental figures.

## Reproducibility notes
 
This repository is organized so that reported results can be traced to code. A few things to know before
re-running:
 
- **Final behavior figures, statistics, and some modeling statistics were made in GraphPad Prism** Behavioral figures and stats are from the values exported by
  `ASD_odor_summary.m` and `ASD_learning_curve.m`. The MATLAB plotting/statistics in `code/behavior/`
  compute and visualize those values but are not the source of the published figures. Some modeling group comparisons of p(engaged) and variance reported were also analyzed in GraphPad Prism (see `code/modeling/README.md` for more detailed information.
- **`exploratory_not_reported/`** holds analyses run during revision but not included in the manuscript
  (`engagement_analysis.m`; `fda_longitudinal_permtest.m`, a functional-data-analysis permutation test
  on the learning curves), kept for reference.
